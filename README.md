# Soulslike Build Planner

Attack rating calculator for Elden Ring, built in TypeScript.

## What works
- Attack rating per damage type, from weapon, upgrade level, stats
- Two-handing bonus and stat-requirement penalty
- Real game data for 5 weapons (generated by a script)
- Unit tests, including cases verified against an independent calculator

## Run it
npm install
npm test
